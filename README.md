# DS_Capstone_Project2
This repository contains multiple Jupyter notebooks for the data cleaning and model training for the project "Using Machine Learning to Analyze Chorus Health and Member Participation". This project analyzes the world of barbershop harmony singing and uses machine learning to analyze chorus and member data and make recommendations to leadership.

## Jupyter Notebooks
1. Barbershop_Data_Cleanup - Clean and compile the data from eight CSVs using SQL.
2. Chorus_Health_Modeling - Use machine learning to classify choruses as at-risk.
3. Member_Cluster_Model_Training - Use machine learning to train a model for grouping members into clusters.
4. Member_Cluster_Model_Pipeline - Run new data through the trained model via a pipeline.
